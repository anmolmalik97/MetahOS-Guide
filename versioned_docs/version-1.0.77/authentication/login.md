# How To Login To Your Instance of MetahOS

Your IT Administrator/Hospital Director would give you the URL to MetahOS

Typically it would be your yourhospital.metahos.com/login

### Login Landing Page

![Login Landing Page](https://m16-cloudinary-imported-assets.s3.ap-south-1.amazonaws.com/Guide/Login_to_MetahOS_fltkuo.png)

### Select User Type

**_Note: Some versions might not have the user type_**

![Select User Type](https://m16-cloudinary-imported-assets.s3.ap-south-1.amazonaws.com/Guide/Select_User_Type_vmvbgy.png)

After entering your credential click on login.

## Doctor sign-in

Doctors can sign in either with their **mobile number** or with the **user ID** the system generated for them — a code such as `INDBOG5`, shown to the administrator when the doctor record was saved and listed in the doctor table.

The user ID is not case-sensitive at login, so it can be typed in lower case.

See [Doctor User IDs](../security/doctor-user-ids.md) for how the ID is built and how to generate IDs for existing doctors in bulk.
