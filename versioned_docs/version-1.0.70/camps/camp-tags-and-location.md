# Camp Tags & Location Capture

When you create or edit a camp, MetahOS lets you **tag** the camp for easy grouping and filtering, and **capture its exact location** as latitude/longitude — either from your device's GPS or by picking a point on a map.

## Tagging a camp

The **Add / Edit Camp** form includes a **Tags** option. Tags let you label camps with reusable categories (for example a programme name, a partner, a region or a campaign), so you can later group and filter camps by tag.

- A camp can carry **one or more tags**.
- Tags are selected from your organisation's tag list, so the same labels stay consistent across camps.

:::tip
Use tags for any cross-cutting grouping you report on — such as the sponsoring programme or partner organisation — so camp lists and reports can be filtered consistently.
:::

## Capturing the camp location

The **Add / Edit Camp** form has a **Location** section at the top with two ways to set the camp's coordinates:

### Use Current Location

Click **Use Current Location** to capture your device's current GPS position. MetahOS fetches the coordinates and can sync the address fields from that location. While it is working, the button shows *Fetching location...*; any problem is shown as an inline error.

### Choose on Map

Click **Choose on Map** to open an interactive map picker. Drag or click on the map to place the camp's marker exactly where the camp is held. The selected point updates the camp's latitude and longitude.

Once a location is set, the form shows the **Selected Location** with the latitude and longitude (to four decimal places) so you can confirm it is correct before saving.

### Why location matters

Capturing accurate coordinates means:

- Camps appear in the right place on map-based views and outreach reports.
- The recorded latitude/longitude can be used for distance and coverage analysis.
